# Academia PC

Página educativa interactiva para aprender sobre el computador. El archivo principal es `index.html` y los modelos 3D se cargan desde la carpeta `models/` mediante rutas relativas.

## Publicar con GitHub Pages

1. Abre **Settings → Pages** en este repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/(root)`.
4. Guarda los cambios y espera a que GitHub publique el sitio.

## Modelos 3D

Los modelos GLB están en `models/`. El HTML referencia los archivos mediante rutas relativas, por lo que no es necesario incrustarlos en el HTML.

Nota: el catálogo de esta versión contiene 16 componentes/modelos únicos. El ventilador no está incluido en esta versión; se añadirá cuando se suba el archivo GLB nuevo correspondiente.
